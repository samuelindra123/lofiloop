# Taruh video demo di folder ini

Rekam layar aplikasi LofiLoop dengan Xbox Game Bar (Win + G), lalu simpan berkasnya
di folder ini dengan nama:

    demo-lofiloop.mp4

Panjang 20 sampai 30 detik. Isi yang paling berguna untuk dilihat calon pengguna:

1. Memilih klip video
2. Memilih berkas audio
3. Menggeser durasi ke 1 jam, sambil memperlihatkan perkiraan ukuran berkas
4. Menekan render, biarkan progresnya terlihat berjalan sebentar

Berkas ini tidak ikut disimpan di repositori kalau ukurannya besar. Ukuran di bawah
5 MB masih aman. Kalau lebih besar, kabari dulu supaya bisa dikecilkan.

Folder ini sengaja ada supaya tempatnya jelas, bukan supaya berkasnya wajib ada.
Selama berkasnya belum ada, halaman beranda menampilkan bagian tempat video itu
dengan keterangan bahwa rekamannya belum tersedia.
